Technical Documentation & System Architecture

Complete engineering guide to the multi-language pipeline, AI tour generator, IoT telematics ingestion, Supabase PostGIS search, data safeguards, and payments in PassionRide.

System Overview

PassionRide is a next-generation Peer-to-Peer (P2P) bike, car, and EV rental marketplace integrated with live IoT telematics, AI itinerary synthesis, and keyless vehicle access.

Hybrid Authentication

Supabase Auth & Firebase Auth integration supporting passwordless magic links, native credentials, and Google OAuth via popup-redirect callbacks.

Multi-Language Engine

Static compiled localizations via Slang (English, Hindi, Bengali, Spanish) combined with real-time AI translation (LibreTranslate) with an LRU cache.

System Architecture

The platform separates user interface state, relational PostGIS database persistence, real-time message streams, and background AI inference:

Built with Flutter (Dart SDK 3.12+). App-wide state is managed via AppState and LanguageProvider using Provider.

  • Interface Engine: Material 3 design system with custom AppTheme light/dark palettes.
  • Multi-Language: Slang generated Dart types (`strings.g.dart`) with zero-latency locale switching.

Backend duties are distributed across cloud endpoints:

Service Responsibilities
Supabase PostgreSQL relational engine, PostGIS radius search, Row-Level Security (RLS), Supabase Auth.
Firebase Cloud Firestore real-time sync, Firebase Cloud Messaging (FCM) notifications.
Razorpay Cross-platform checkout gateway with web bridge stubs (`razorpay_web_bridge.dart`).

AI Services powers intelligent features:

  • Google Gemini 1.5/2.0: Generates multi-day adventure trip itineraries (`GeminiAIService`).
  • Groq LLM API: Fast fallback engine for high-throughput AI text synthesis.
  • LibreTranslate: Translates dynamic user reviews & chat messages with LRU caching.
  • Document OCR: Scans & validates Driving Licenses and Registration Certificates (`DocumentOcrService`).

Multi-Language & LRU Cache Architecture

To eliminate translation latency and avoid external API quota limits, PassionRide uses a hybrid dual-layer translation pipeline:

1. Slang Static Code Generation

UI labels, buttons, navigation text, and system messages are compiled into strongly-typed Dart classes from JSON translation files (en.i18n.json, hi.i18n.json, bn.i18n.json, es.i18n.json).

2. In-Memory LRU Cache Lookup

When user-generated content requires dynamic translation, LanguageProvider checks its internal LRU Cache. If found, the translated text is returned instantly (0ms latency).

3. LibreTranslate Service Fallback

On cache miss, LibreTranslateService dispatches a REST API call to the LibreTranslate instance, updates the LRU cache, and renders the result asynchronously.

Data Model Safety & Type Guards

To safeguard against database type mismatches (e.g. Postgres numeric types returned as String or int vs double), all model constructors run values through private parsing functions in models.dart:

Dart Safe Parsing Snippet 
double _parseDouble(dynamic value, double defaultValue) {
  if (value == null) return defaultValue;
  if (value is num) return value.toDouble();
  return double.tryParse(value.toString()) ?? defaultValue;
}

OCR Document Verification & KYC

The DocumentOcrService processes images of Driving Licenses, RC permits, and National IDs to verify identity compliance and update user trust scores.

Telematics & Diagnostics Hub

Real-time vehicle telemetry monitors battery SoC, tire pressures (TPMS), OBD trouble codes, and GPS location coordinates.

Stream Chat & Anti-Leakage Protection

In-app chat is powered by StreamChatService. Outgoing chat messages are scanned by PlatformLeakageFilter to detect and block off-platform bypass attempts (e.g. sharing phone numbers or email addresses).
