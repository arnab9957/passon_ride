Technical Documentation

A comprehensive reference of the architectural workflow, data parsing safeguards, and integration APIs within the PassionRide Peer-to-Peer bike and car rental application.

System Overview

PassionRide is a modern Peer-to-Peer (P2P) bike and car leasing platform. The architecture is optimized for low-latency synchronization of real-time GPS coordinates, robust security frameworks, and seamless cloud integrations across platforms.

Robust Authentication

Secured with Supabase identity wrappers, supporting native username/password auth alongside Google OAuth utilizing a hybrid pop-up callback framework.

Live Telematics

Real-time vehicle tracking pipeline connected to GPS coordinates, TPMS sensors, fuel levels, engine lock controls, and OBD-II diagnostics logging.

Data Model Safety

Database responses (especially from PostgreSQL numeric and numeric-like columns) frequently arrive with dynamic types (e.g. integer schemas, string hashes, floating-point formats, or null values). Direct type-casting (e.g. map['field'] as double) causes runtime crashes.

To prevent this, the system processes all incoming database mapping through robust private utility functions at the top of models.dart:

Dart Safe Utilities 
double _parseDouble(dynamic value, double defaultValue) {
  if (value == null) return defaultValue;
  if (value is num) return value.toDouble();
  return double.tryParse(value.toString()) ?? defaultValue;
}

int _parseInt(dynamic value, int defaultValue) {
  if (value == null) return defaultValue;
  if (value is num) return value.toInt();
  return int.tryParse(value.toString()) ?? defaultValue;
}

bool _parseBool(dynamic value, bool defaultValue) {
  if (value == null) return defaultValue;
  if (value is bool) return value;
  if (value is num) return value != 0;
  final str = value.toString().toLowerCase();
  return str == 'true' || str == '1' || str == 'yes';
}

Every model class (such as Vehicle, Tour, Booking, and TelemetryLog) wraps numeric and boolean fields using these functions, rendering the client immune to database field conversion crashes.

Google OAuth: Hybrid Popup-Redirect Flow

In Flutter Web local development, standard OAuth redirection often terminates flutter run debug sessions. Direct browser popups are blocked by Google's security guidelines if the development host/port is not whitelisted.

To bypass these limitations seamlessly, PassionRide implements a hybrid popup-redirect flow:

1. Initiate Auth Request

The client opens a browser popup window pointing directly to the Supabase OAuth authorization URL:

https://gxqlsogewjjkcdetubuv.supabase.co/auth/v1/authorize?provider=google&redirect_to=${Uri.base.origin}
2. Google Consent Verification

Google evaluates the authorization request. Since the origin is the Supabase domain (which is registered as an approved redirect URI), Google presents the account chooser pop-up without any local IP or origin blocks.

3. Local Callback Resolution

After consent, Google redirects the popup back to Supabase, which forwards it to the parent tab's origin (localhost) with access and refresh tokens contained in the URL hash fragment.

4. Auth State Synchronization & Auto-Close

The popup loads the entrypoint page, initializing the Supabase client which automatically reads the tokens from the hash and writes them to local storage. Because the parent and popup share local storage, the parent tab updates immediately. The popup closes itself dynamically.

Telematics & Real-Time Tracking

The telematics subsystem persists telemetry snapshots from active vehicles, verifying TPMS sensors, fuel levels, locks, engine states, and OBD code arrays:

Telematics Parameter Description Type
latitude / longitude GPS coordinates for live tracking. Double (Safe-parsed)
batterySoc Electric battery state of charge percentage. Integer (Safe-parsed)
tpmsFrontPsi / tpmsRearPsi Front and rear tire pressure (PSI) alerts. Double (Safe-parsed)
engineOn / locked State indicators of the vehicle's engine and lock. Boolean (Safe-parsed)
